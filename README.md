## 🚀 Featured Projects

### 🤖 Agentic AI Interview & Assessment Platform
**LangGraph · Hybrid RAG · Qdrant · BM25 · Gemini · Streamlit**

Multi-agent technical interview platform with semantic caching, hybrid retrieval, quality-gated LLM routing, and automated competency assessment.

**Engineering highlights:**
- Hybrid retrieval using **Qdrant + BM25 + Reciprocal Rank Fusion**
- Composite-namespaced semantic cache with a **negation-polarity guard**
- Tiered **Gemini Flash / Pro** routing with speculative refinement
- Benchmarking across **1,000 sessions / 2,479 turns**
- Reported **92.68% cost reduction vs. all-Pro routing baseline**

➡️ [View repository](https://github.com/UjjwalS2/LangGraph-based-AI-interview-agent)
